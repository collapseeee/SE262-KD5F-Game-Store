# 🎮 KD5F - Game Store Project
KD5F is a full-stack e-commerce web application for digital video games. It features a dual-user system (Buyers and Sellers), a dynamic shopping cart with instant navbar updates, and a robust media carousel for product details.

## 🚀 Features
For Buyers
- Dynamic Shopping Cart: Add/Remove games with instant UI feedback in the navbar "bubble" popup.

- Wishlist System: Save your favorite games for later.

- Smart Search: Search by name or filter by multiple categories simultaneously.

- Media Gallery: High-fidelity product pages with YouTube embeds and image carousels.


For Sellers
- Inventory Dashboard: Manage your listings in one centralized view.

- Product Management: Full CRUD (Create, Read, Update, Delete) for games, including system requirements and gallery uploads.

- Sales Tracking: Real-time updates to total sales and revenue.

## 🛠️ Tech Stack
Backend: Node.js, Express.js

Frontend: EJS (Embedded JavaScript), Bootstrap 5, jQuery

Database: MySQL

DevOps: Docker, Docker Compose

Library/Tools: Axios, Multer (File Uploads), Express-Session, Animejs, MapLibre, Postman, Figma
